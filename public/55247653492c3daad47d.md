# はじめに
今回はJISOUのイベントであるHARD DAYに参加して得た気づきをさくっと書いていこうと思います。
# そもそもHARD DAYとは
簡単に説明するとJISOUのコーチが普段行っているスケジュールをJISOUのみんなでこなしていくイベントです。基本的にはポモドーロを活用した学習を各自進めていくのですが、合間にお互いのコードをリファクタリングしあったり体を動かす時間などのアクティビティがあったりします。メンバー同士交流する時間も多かったです。
# HARD DAYで得た気づき
### 言語化のスキルは超重要
HARD DAYではいきなり「0秒思考」というものをやりました。これは与えられたお題に対する自分の考えを1分という短い時間でなるべくたくさん(目標としては10個)書き出すというものです。お題は以下のようなものが出されました。
```
- なぜプログラミングの勉強をしているのか
- 自分の得たい未来は何か
- そのためにこれから何をすべきか
- ...
```
皆さんは各お題に対して1分でどれくらい書き出せますか？自分は多くて5個、基本は2,3個しか書き出せませんでした。このように自分の考えを短い時間で紙に書き出すには言語化の力が必要です。最初は言語化のスキルって本当に必要なのかと思っていたのですが、よくよく考えてみるとエラーで詰まっている際に誰かに質問するときや面接で想定外の質問が飛んできた時など言語化スキルが必要な場面はたくさんあるなと思いました。HARD DAYでは0秒思考の他にもプライミング瞑想や他の方のコードリファクタリング、感想共有など強制的に言語化の訓練をする場面がたくさんあり言語化の難しさと大切さを実感できました。

### 単に技術を学ぶだけでは差別化できない
スケジュールの中でpivotのYoutube動画をみんなでみて感想を共有し合う時間がありました。その中で日本はモノを作る技術はあるが、それをユーザーに十分に提供できる人が少ないという内容があり技術を学ぶだけでなく、どこにニーズがあるのかやマーケティングなどの経営(金融や会計)に関する知識も学習し常にアップスキリングしていく重要性が語られていました。
ここはJISOUでの考え方にも似ていますが、やはり単に技術を学ぶだけでなくその技術を使ってどう世の中に価値を提供できるか重要だと感じました。
また動画の後半ではリスクを恐れずチャレンジすることの重要性について話されていて、失敗しても死ぬわけではないしどうせ100年経ったら死ぬなら成功するかわからなくてもチャレンジした方が良いというゲストの言葉に少し感動しました。

### 自分が普段いかに勉強していないか
最初に説明したようにHARD DAYでは基本的にポモドーロ式に学習を進めていきます。ポモドーロとは「25分学習したら5分休む」を1ポモドーロとしこれを繰り返しながら作業していくことで、集中力を保つことができるようにする学習方式です。しかしこれがなかなか疲れる... 普段自分は休憩を取る際は30分くらい取ることが多いので、5分しか休憩がないポモドーロ式の学習は体力的になかなかしんどかったです。いかに普段自分が勉強していないかを自覚できました。とはいえこの方式のおかげで集中力を保ちながら作業できたので、普段1人で学習する時よりもかなりのスピードで学習を進められた気がします。
