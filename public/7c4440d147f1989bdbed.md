# はじめに
supabaseで昨日のレコードを削除するコマンドを実行した際にエラーが出たのでその解決策を書いていきます。
# 問題
npx tsx batch/index.tsのコマンドを打つと以下のエラーが出る。index.tsには昨日追加されたレコードを削除する処理が書かれています。
```
Error: supabaseUrl is required
```
# 解決策
supabase.tsに以下の一行を追加する。
```ts
import 'dotenv/config';
```
dotenvは環境変数を.envファイルから読み込むことができるNode.jsのライブラリみたいです。今回の場合適切に.envに定義されてるsupabaseの情報が適切に読み込まれていなかったためエラーになっていたみたいです。

# 追記: 注意点と補足
上記の解決法で一応問題となっていたエラーは消えますが、firebaseでデプロイされているURLを確認すると画面が真っ白になってしまいました。コンソールで確認すると以下のエラーが出ます。
```
Uncaught ReferenceError: process is not defined
```
なのでimport 'dotenv/config'をsupabase.tsに追加するのではなく、コマンド実行時に直接.envの環境変数を渡してあげると良いです↓
```
npx tsx --env-file=.env  batch/index.ts
```
 またgithub actionsのパイプラインでは.envを読み取れないので以下のように渡してあげる必要があります。
 ```yml
      env:
        VITE_SUPABASE_URL: ${{ secrets.VITE_SUPABASE_URL }}
        VITE_SUPABASE_ANON_KEY: ${{ secrets.VITE_SUPABASE_ANON_KEY }}
      run: npx tsx batch/index.ts
 ```

# おわりに
dotenv自体はjestの環境構築でも使っていたのですが、いまいち何のためのライブラリかはわかっていませんでした。今後はなぜそのライブラリが必要なのかも少しずつ考えるようにしていきます。
