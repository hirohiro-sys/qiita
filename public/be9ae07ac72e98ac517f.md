# はじめに
git pushした際にReactアプリを自動デプロイする手順を書いていきます。前提としてfirebaseにアプリをすでにデプロイしている状態を想定しています。

# 早速やってみる
基本的には以下の3ステップになります。
```
① firebase login:ciコマンドでアクセストークンを発行
② 発行したトークンをgithubに登録
③ ymlファイルにcicdのコードを書いてpush
```
### 1. firebase login:ciコマンドでアクセストークンを発行
そのままですが以下のコマンドを打つとgoogleログインページに飛ぶので、正常にログインできるとターミナルにアクセストークンが発行されているはずです。
```
$firebase login:ci
```
### 2. 発行したトークンをgithubに登録
該当リポジトリのSettings > Secrets and variables > Actions > New repository secretから先ほど発行したトークンを登録してください。nameはとりあえずFIREBASE_TOKENでいいと思います。ちなみにsupabaseを使ってる場合は.env内のURLやANON_KEYも登録しないとうまくいかないので注意です。

### 3. ymlファイルにcicdのコードを書いてpush
まず必要なディレクトリとファイルを作っていきます。
```
$mkdir -p .github/workflows
$touch .github/workflows/deploy.yml
```
そしたらdeploy.ymlにcicdのコードを書いていきます。今回はsupabaseを利用しているのでreactアプリをbuildする際に.envの環境変数を指定しています。
```yml
name: Deploy to Firebase

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Setup Node.js
        uses: actions/setup-node@v2
        with:
          node-version: "18"

      - name: Install dependencies
        run: npm install

      - name: Run build
        run: npm run build
        env:
          VITE_SUPABASE_URL: ${{secrets.VITE_SUPABASE_URL}}
          VITE_SUPABASE_ANON_KEY: ${{secrets.VITE_SUPABASE_ANON_KEY}}

      - name: Install firebase-tools
        run: npm install --save-dev firebase-tools

      - name: Deploy to Firebase
        uses: w9jds/firebase-action@master
        with:
          args: deploy --only hosting
        env:
          FIREBASE_TOKEN: ${{ secrets.FIREBASE_TOKEN }}
```
ここまでできたらアプリ内の見た目を少し変えてpushしてみてください。おそらく変更が反映された状態でデプロイされているはずです。
