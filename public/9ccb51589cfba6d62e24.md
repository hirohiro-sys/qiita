# はじめに
react,typescriptの環境をviteで作った際にApp.tsxのいたるところに警告文が表示されたのでその解決策を書いていきます。

# 問題
プロパティ 〜 は型 'JSX.IntrinsicElements' に存在しません。という警告が大量に出る。
![スクリーンショット 2024-07-30 22.29.01.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3279945/da0d729c-7a11-6250-12b5-0b8c4503bdd1.png)
心臓に悪いですね。

# 解決策
tsconfig.node.jsonの以下の箇所を修正する(tsconfig.app.jsonもある場合はそちらも)。

```diff_json
- "moduleResolution": "bundler"
+ "moduleResolution": "node"
```
これで警告が消えました。
