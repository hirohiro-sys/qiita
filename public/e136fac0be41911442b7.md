# はじめに
Firebase Authの初期化でエラーが出たので解決策を書いていきます。

# 問題
そもそもfirebaseの初期化周りでエラーが出て画面が真っ白になる。
```
TypeError: firebaseApp.firestore is not a function
```
以下のコードでエラーになる
```js
/*---firebase.js---*/
import firebase from 'firebase/compat/app';
import 'firebase/compat/auth';
import 'firebase/compat/firestore';

const firebaseApp = firebase.initializeApp = ({
// 省略
});


const db = firebaseApp.firestore();
const auth = firebase.auth();

export { db, auth };
```

# 解決策
initializeAppの呼び出し方が間違っていたみたいです。以下のようにすると正常に初期化ができました。
```js
/*---firebase.js---*/
import firebase from 'firebase/compat/app';
import 'firebase/compat/auth';
import 'firebase/compat/firestore';

const firebaseConfig = {
// 省略
};

const firebaseApp = firebase.initializeApp(firebaseConfig);

const db = firebaseApp.firestore();
const auth = firebase.auth();

export { db, auth };
```

# おわりに
Firebase Authを始めて使ったのですが、手軽に認証処理が実装できて便利ですね👀
