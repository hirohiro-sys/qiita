# はじめに
TanStack Tableというリッチなテーブルライブラリでページネーションとチェックボックスを作っていた際に詰まったので記事にします

# 問題
2ページ目以降でチェックボックスを押すと1ページ目に戻ってしまう
(コードは長いので省略します)

# 解決策
すみません、公式ドキュメントを見たら一瞬でした。デフォルトではページの状態が変更されるとpageIndexが0にリセットされてしまうみたいです。autoResetPageIndexを指定すればなおりました。

https://tanstack.com/table/v8/docs/guide/pagination#auto-reset-page-index

useEffect周りが怪しいと思ってコードいじってみたり、googleやaiに聞いてみたりしましたが解決できずふとドキュメントを覗いてみたらガッツリ書いてありました。

# おわりに
公式ドキュメントを見る癖をつけたい
