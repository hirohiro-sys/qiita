# はじめに
react-hook-formを利用して0以下の数値を入力した際にバリデーションエラーが出ることのテストを実装してる際に以下のエラーが出たのでその対処法を書く。

# 問題
以下のエラーが出る。
```
Unable to find an element with the text: ⚠️学習時間は1以上である必要があります。
```
問題のコード↓
```js
 test('学習時間が1以上でないときに登録するとエラーが出る', async () => {
    // 学習記録を登録するためのモーダルを開く
    const registerButton = screen.getByTestId('add-record-button');
    userEvent.click(registerButton);
  
    // 学習時間を入力せずに送信ボタンをクリック
    await waitFor(() => {
      const submitButton = screen.getByTestId('submit-button');
      userEvent.click(submitButton);
    });
  
    // 学習時間は必須項目のエラーメッセージが表示されていることを確認
    await waitFor(() => {
      expect(screen.getByText('⚠️学習時間は必須入力項目です。')).toBeInTheDocument();
    });
  
    // 学習時間を入力する
    const timeInput = screen.getByTestId('time-input');
    userEvent.clear(timeInput);
    userEvent.type(timeInput, '-1'); // 0以下の値を入力することでエラーが発生することを確認
  
    // 再度送信ボタンをクリック
    userEvent.click(screen.getByTestId('submit-button'));
  
    // 学習時間が1以上である旨のエラーメッセージが表示されていることを確認
    await waitFor(() => {
      expect(screen.getByText('⚠️学習時間は1以上である必要があります。')).toBeInTheDocument();
    });
  });
```
コンソールログで確認してみたところ、-1を入力しているにもかかわらず'⚠️学習時間は必須入力項目です。'のままで'⚠️学習時間は1以上である必要があります。'が出力されていないためテストがエラーになっています。

# 原因 & 解決策
現状だと入力をする箇所で入力が終わる前にsubmit-buttonが押されてしまうため、適切なエラーメッセージが表示されません。なのでしっかり入力が終わるまで待ってあげる必要がありました。
```diff_javascript
   // 学習時間を入力する
    const timeInput = screen.getByTestId('time-input');
    userEvent.clear(timeInput);
-   userEvent.type(timeInput, '-1'); // 0以下の値を入力することでエラーが発生することを確認
+   await userEvent.type(timeInput, '-1'); // 0以下の値を入力することでエラーが発生することを確認
```
これでテストが正常に動作するはずです。~~初心者エラーな気がしますが1時間くらい解決に時間かかりました。~~

```js
  test("学習時間が1以上でないときに登録するとエラー", async () => {

    });
  });
```

# おわりに
どのタイミングで処理が完了されるまで待ってあげる必要があるのかなんとなくわかってきました。あと今回のエラーとは関係ないですがテストを意識してApp.tsxなどのメインロジックを書く方が良いとなんとなく思いました。より良いコードを書いていけるよう精進していきたいです。
