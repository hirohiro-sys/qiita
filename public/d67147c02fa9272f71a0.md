# はじめに
jQueryでなぜかイベントが正常に実行されなかったので原因を調べてみました。
# 問題
以下のようにクリックイベントを実行してもなぜか処理が実行されない。
```js
$(".demo").on("click", () => {
    console.log("クリックしました");
});
```
# 原因&解決策
クリックする要素(今回の場合は.demo)がjsなどにより後から追加された要素の場合は処理が正しく実行されないみたいです。今回の場合はページが全て読み込まれた後にjQueryで追加した要素をクリックしているのが原因でした。以下のようにdocumentを使って記述することで正常に動作するようになりました。
```js
$(document).on("click",".demo", () => {
    console.log("クリックしました");
});
```
# 追記: 注意点と補足
一応上記のやり方で処理は正常に行われますが、document内の全てのクリックイベントを受け取ってから指定したクリックイベントを実行するため、クリックイベントが増えてくるとパフォーマンスに影響を与える可能性があるみたいです。なので何も考えずdocumentにするのではなくクリックイベントを受け取る範囲を狭めてあげることでパフォーマンスを改善できます。
```js
$("#元々あった親要素").on("click",".demo", () => {
    console.log("クリックしました");
});
```
上記のように後から追加された要素である.demoから元々存在する親要素探して指定してあげることでdocumentを使わなくても動くようになりました。

# おわりに
コードは合ってるのになんで実行されないのか自分で色々試していたら解決に少し時間がかかってしまいました。検索してみると結構同じ内容がヒットしたのですぐ調べてみるのも大事ですね。
