# はじめに
以前作った学習記録アプリはバックエンドを実装していなかったのでリロードするとデータが全て消えてしまいました。なので今回は以前の学習記録アプリのバックエンドにsupabase、そしてデプロイとテストを自動化するためにgithub actionsを導入しました。

https://qiita.com/bisketoriba/items/2276b48af22511ae1db8

# 作ったもの
前回と同じで特にスタイリングはしてません(なので見た目上は変化0です)。supabaseでデータを保持するようにしたのでリロードしてもデータが保持されるようになっています。

# 今回追加した技術

### バックエンド
- supabase
### デプロイ
- firebase
### テスト
- jest
- testing-library
### CICD
- github actions

# 気づき
今回はsupabaseでのバックエンド実装やfirebaseでのデプロイなど今までやったことない技術をたくさん使ったのでとても苦労しました。どれも特に教材とかでは学習せずネット記事や公式ドキュメントを見ながら進めていったので、自分で調べながら物事を解決する力が少しずつついてきた気がします(gptとも仲良くなれた)。また解決に時間がかかったエラーや勉強になったことは都度記事にしていたので、アウトプットも習慣化できるようになってきました。今回実装進めながら自分が思ったより以上に公式ドキュメントが苦手という発見もできたので、今後は何かあったらまず公式ドキュメントを見るという意識で実装を進めて行こうと思います。

# おわりに
アプリを作るって大変ですね。今後はこの学習記録アプリにTypeScriptやデザインをリッチにするためのChakraUIなども導入していきます。
