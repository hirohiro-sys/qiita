# 苦労したこと
今回は前回の学習記録アプリとほとんど同じ技術しか使っていないので機能実装自体は割とスムーズにできました。苦労した点があるとすれば学習記録アプリの時と違い、テーブルを3つ使う必要があった点です。初めはユーザーとスキルのデータをつなぐ中間テーブルの概念がよく分からず苦労しましたが、調べながら落ち着いて考えればそこまで難しいものではありませんでした。supabaseはRDBなので少しデータベース設計やSQLの知識があったらより使いこなせそうな気がします。

# 学べたこと
### 基本的なアプリ開発の流れを把握できた
ここまで学習記録アプリとデジタル名刺アプリを作りながら、基本的なアプリ開発の流れは共通していることを知ることができました。以下基本的な開発のステップになります。
```
1. VITEでReact(Typescript)の環境構築
2. Firebaseにデプロイ
3. Jestの環境構築
4. CICD構築
5. Supabaseの初期設定
6. 機能実装
7. テスト
8. 随時機能追加やリファクタリング 
```
今回は題材が決まっていたのですぐに開発に取り掛かれましたが、実際の個人開発では自分でアイディアを決めたり最低限何を機能実装するかなどを決めていく必要があるので、今後はそのあたりにもチャレンジしていきたいです。
