# はじめに
最近Reactを勉強し始めたので、手始めにQiitaでみた以下のReactのロードマップをやってみようと思います。

https://qiita.com/Sicut_study/items/78910cd8d103b8d45a73
# 実装してみた
```jsx
import { useState } from "react";
import axios from "axios";

function App() {
  const [image, setImage] = useState("https://picsum.photos/800");

  const onClickGetRandomImage = () => {
    axios
      .get("https://picsum.photos/800")
      .then((res) => setImage(res.request.responseURL));
  };

  return (
    <>
      <img src={image} width="500px" height="500px" alt="ランダムな画像" />
      <button onClick={onClickGetRandomImage}>画像を変更</button>
    </>
  );
}

export default App;

```
# 注意点
ロードマップ内の以下のURLでは現在ランダム画像を取得できないようです。
```
https://source.unsplash.com/random
```
ですのでこちらの記事参考に以下のURLを使えばランダム画像を取得できます。
```
https://picsum.photos/800
```
https://ttydev.com/post/other/unsplash-random
