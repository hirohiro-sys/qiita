# はじめに
先日サイバーエージェントのSpecialized Boot Campというインターンに参加してきたので、そこでの学びや感想、反省点などを色々書いていこうと思います。

# なぜ参加したか
もちろん就活の一環もありますが、1番はサイバーエージェント規模の会社の開発スタイルや働き方、社員や学生の方々のレベル感を知りたかったからです。普段は韓国の大学に通っているので、日本の学生エンジニアの方と話す機会は全くないですし、業務もリモートで行なっているため、出社して行う今回のインターンはとても新鮮な体験でした。

# インターン概要

### 参加したインターン
2週間でWebフロントエンド開発を行うインターンに参加しました。

https://www.cyberagent.co.jp/careers/students/event/detail/id=31569
### 選考内容
書類と面接(エンジニア、人事)の2ステップでした。面接はWebフロントエンドの基本的な部分やこれまでの開発経験に関する質問が多かったです。面接を受けて振り返るだけでもなかなか勉強になるなと思いました。

### 配属先
自分の配属先はCIU(CyberAgent group Infrastructure Unit)という部署でした。以下サイトにも記載されていますが、主に社内用クラウドサービスであるCycloudの開発やAWS/GCPを利用している他事業部のサポートなど、CAグループ全体のインフラ領域を支える組織です。社内用クラウドがあることに驚きでした。

https://it.cyberagent.group/team/ciu/

### 何をしたか
2週間のインターンとはいえ初日と最終日はほとんど作業しなかったので、実質7日ほどのタイトなスケジュールでした。自分が行ったタスクはCycloud内のサービスの1つであるContainer RegistryのWeb UI内製化でした。元々はHarborというOSSのコンテナレジストリが使われていたのですが、他のCycloudサービスとUIの統一感を持たせることでの認知負荷低減やブランディングなどが目的でした。

以下インターンの大まかな日程です。

| 日数   |  やったこと  |
| ---- | ---- |
|  Day1  |  PCの初期設定、オンボーディング、インターンで行う課題の概要把握
|  Day2〜4  | 課題やプロダクトについてのキャッチアップ、設計
|  Day5〜7  |  実装  |
|  Day8〜9  |  仕上げ、成果発表

他にはインターンの方や他事業部の方とのランチ交流、懇親会などがありました。

# インターンでの学びや感想
### 明確な評価基準と目標設定
印象的だったのはインターンが始まる1週間くらい前からインターンでの評価基準が与えられ、それに対する目標設定を行う必要があったことです。明確な評価基準があることでインターン(というよりサイバーエージェント)でどのような成果が求められているかがわかり、目標設定の軸も定まりやすかったです。とは言っても自分は最初作った目標に抽象的な部分が多く、トレーナーの方に指摘いただくことが多かったので、今後はより具体で目標を言語化できるように改善する必要があると感じました。
サイバーエージェントのサイトを色々覗いたところ良い目標設計と振り返りの力をやはり重要視しているみたいです。

https://www.cyberagent.co.jp/way/list/detail/id=28128

### 周りの技術力の高さ
他のインターンの方々は中学の頃からプログラムを書いていたり、普段からガッツリ開発業務をこなしている人ばかりで学生とは思えないような技術力の方ばかりでした。社員の方々は単にOSSを使うに留まらず、自ら不具合修正をしたり内部実装を把握していたりと技術を深いレベルで理解している方が多かった印象です。技術力の高い方々と交流しながら自分のハード・ソフトスキルの不足を感じたのと同時に、自分の基準が引き上げられたと感じています。

### 新しい技術
配属部署がインフラ関連の部署だったので、k8sの用途やコンテナイメージなどについて調べるところから始まり、インフラ周りの技術を把握できました。また今回はWeb UIの内製化なので実装自体は0→1で行う必要があったのですが、ベースとなるクリーンアーキテクチャのコードを予め用意してくださっており、クリーンアーキテクチャの理解も深まりました。他にもgRPCやNext.jsのパラレルルートなどこの2週間で多くの新しい技術に触れることができて楽しかったです。トレーナーの方が関連技術や社内ツールに関する説明を意識的にしてくださったのもありがたかったです。

# 改善・反省点
### +aの成果を出す必要があった
一応最低限のWeb UI実装はできたのですが、もっと+aの成果にこだわる必要があると思いました。先ほど少し書きましたが、今回行ったことはAPI経由で取得したデータをCloudscapeというUIライブラリを用いていい感じに表示する的な要件だったので、GETメソッドだけでなくPOSTメソッドを用いた追加処理の実装もしたかったです。併せて、実装前に簡単なモックを作成してチーム内外の方々にFBをもらう動きや他のCycloudサービスの課題の発見・提案、UI/UXに強くこだわるなど+aの成果を出す行動ができたら良かったと思います。今後は限られた時間の中でどれだけ+aの成果を出すかを強く意識していきたいです。

反省点を書き出したらこの記事が終わらなくなってしまうのでここまでにしておきます。

# サイバーエージェントの感想
ありきたりかもですが社内転職などの制度により多種多様な事業部に関われる点が魅力的だと思いました。若手の裁量も強いと感じたので、落ちてきたタスクをやるだけでなく自ら課題を見つけ提案・解決していくマインドがあればカルチャーマッチしやすいと思います。トレーナーや人事の方含め気さくで親切な方が多く、とても雰囲気の良い会社でした。
