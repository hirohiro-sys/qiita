# はじめに
以前はReactアプリをpush時にfirebaseにデプロイしました。今回はpush時に自動テストも走らせていきます。jest,testing-libraryの環境が整っていることが前提になります。

https://qiita.com/bisketoriba/items/be9ae07ac72e98ac517f

# 早速やってみる
まず適当にsrc/tests/sample.spec.jsを作ってください。今回はサンプルとしてtrueがtrueであることをテストしていきます。
```js
/*---sample.spec.js---*/
describe("Sample Test", () => {
    it("should return true", () => {
      // 成功させる場合
      expect(true).toBe(true);
      // 失敗させる場合
    　　　　// expect(true).toBe(false);
    });
  });
```

以前のymlファイルのコードを少し修正します。supabaseでの環境変数を利用しているのでテスト時もこれを指定してあげないとエラーになります。
```diff_yaml
name: Deploy to Firebase

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Setup Node.js
        uses: actions/setup-node@v2
        with:
          node-version: "18"

      - name: Install dependencies
        run: npm install

-    　　- name: Run build
-       run: npm run build
-       env:
-         VITE_SUPABASE_URL: ${{secrets.VITE_SUPABASE_URL}}
-         VITE_SUPABASE_ANON_KEY: ${{secrets.VITE_SUPABASE_ANON_KEY}}

+     - name: Run build and tests
+       run: |
+         npm run build
+         npm run test
+       env:
+         VITE_SUPABASE_URL: ${{secrets.VITE_SUPABASE_URL}}
+         VITE_SUPABASE_ANON_KEY: ${{secrets.VITE_SUPABASE_ANON_KEY}}

      - name: Install firebase-tools
        run: npm install --save-dev firebase-tools

      - name: Deploy to Firebase
        uses: w9jds/firebase-action@master
        with:
          args: deploy --only hosting
        env:
          FIREBASE_TOKEN: ${{ secrets.FIREBASE_TOKEN }}
```
これでpushしたらテストが実行され、firebaseへのデプロイも行われるはずです。
