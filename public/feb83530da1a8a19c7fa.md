# はじめに
ViteでReactの環境構築をはじめてしたのですが、なぜ最近Viteで環境構築をしてる人が多いのか気になり違いを軽く調べてみました。

# CRAとViteそれぞれの環境構築を見てみる
### CRAの場合
```
npx create-react-app プロジェクト名
```
### Viteの場合
CRAとは違い別途npmインストールする必要があるみたいです。
```
npm create vite@latest プロジェクト名 -- --template react
cd プロジェクト名
npm install
```
# なぜViteがいいのか
ネット記事で色々みてみた感じだと以下のメリットが挙げられます。
- 初期の立ち上げが早い
- ビルド時間が短い
- 生成物が非常に軽量
- カスタマイズしやすい
- react以外でも使える

最近学習しはじめた方で特にカスタマイズやパフォーマンスが必要なくコマンド1つで環境構築したい方はCRA、少し慣れてきて開発体験にこだわっていくならViteという感じでしょうか？
# おわりに
Viteいいですね。
